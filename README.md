# Audio-Only-Shooting-Range

- Targets spawn around the player at random directions and distances, and the only way to find them is by ear. The screen is blacked out during play. All audio is authored in FMOD and spatialized through Steam Audio, using the **Steam Audio FMOD Studio plugin**.
